# 帝国备战室 · AOE4 ReadyRoom

Windows 上的非官方《帝国时代 IV》辅助工具，包含“自动训练村民工具”、“快捷键练习”、“开局流程”和“文明胜率”四个页面。宽窗口显示侧栏，窄窗口切换为顶部导航。源代码可双击 `start.bat` 运行（需要 Python）；无 Python 的电脑可运行 `dist\AOE4ReadyRoom.exe`。`build_exe.bat` 用于重新生成单文件 EXE。应用图标源文件在 `assets\aoevillager.svg`，构建时生成多尺寸 ICO，嵌入 EXE，并用作窗口与任务栏图标。

## 自动训练村民工具

此子页面保留简单模式、自定义模式、全局开关与悬浮窗。切换到“快捷键练习”时，会先停止自动训练、隐藏悬浮窗，并暂停自动训练的全局快捷键；返回时恢复悬浮窗和快捷键。

### 简单模式

设置选中 TC 快捷键（默认 `H`）、国家预设、单个村民训练时间 `t`、训练村民快捷键（默认 `Q`）、每轮村民数 `n`（默认 2）。国家预设为“常规”20 秒、“金帐汗国”37 秒、“法兰西”17 秒；选择后会填入对应的 `t`，手动修改 `t` 时切换为“自定义”并保留输入值。每轮原子按键序列为：

`Ctrl+0 → H → Q × n → 0 → Ctrl+Alt+0`

上面三个编队操作是简单模式内部步骤，不在简单设置页显示。**每轮**都会执行 `Ctrl+0`，不是仅启动时一次。下轮计划时间从本轮**第一次 Q 按下**开始计算，间隔为 `t × n` 秒。如果一轮操作耗时超过该间隔，下轮会延后，且至少留 250 ms 的未屏蔽窗口。简单模式步骤间隔固定为 2 ms；这个间隔是目标值，Windows 和游戏调度不能保证严格毫秒精度。

### 自定义模式

可自由增加、删除按键步骤；每步支持单键或 2–3 键组合，例如 `CTRL+ALT+0`。可分别设置步骤间隔（ms）与循环时间（秒）。首次默认是原 PulseClick 当前配置：`Ctrl+0, F11, Q, Q, 0, Ctrl+Alt+0`，步骤间隔 2 ms，循环时间 40 秒。自定义模式从第 2 步按下开始计算下一轮。

两个模式共用全局开关快捷键，默认 `F6`。切换模式会停止当前运行。悬浮提示在设置窗口开启期间可以移动和拉伸；关闭设置后鼠标点击穿透。设置保存在当前用户的 Windows Qt 配置中。

简单模式不使用整页滚动条，设置卡片会随窗口宽度调整布局；自定义模式的可增删步骤列表仍可滚动。所有数字设置框和国家预设下拉框都不会因鼠标滚轮划过而改变数值；仍可直接输入或选择，数字框也可使用键盘方向键与框内按钮调整。

## 快捷键练习

原生 PyQt6 页面，不再使用 Qt WebEngine 或在运行时加载 HTML。练习内容从原始 `D:\Games\AOE4\aoe4-hotkeys-single.html` 迁移为 `assets\practice\catalog.json`；原文件不修改。首次进入先显示可搜索的文明旗帜网格，选定文明后进入练习，也可随时返回更换。练习页提供学习模式、训练模式、练习次数与建筑选择，支持两键顺序输入、学习提示、进度统计和本次运行的错题本。离开练习子页面时自动暂停。文明和建筑图标都随单文件 EXE 打包，运行时不需要网络；文明选择页复用开局流程的大幅旗帜素材。图片来自原页面引用的 [AoE4 World 数据仓库](https://github.com/aoe4world/data)及文明图标地址；`scripts\import_hotkey_catalog.py` 是一次性数据迁移脚本，不参与运行。

## 开局流程

原生 Qt 阅读页，采用 AOE4 Guides 的深蓝／金色视觉层次与公开阅读路径：文明旗帜网格 → 热门／经典／最新流程卡片与本地筛选 → 时代时间轴及可展开的经济曲线 → 图标化原文步骤表 → 逐步播放或置顶悬浮播放。图标悬停显示原站名称、说明及成本；常见资源、单位和建筑另有人工整理的中文说明。可生成手机扫码查看原站流程的二维码，但不显示视频。页面保留作者与来源链接，不对作者的流程文字做机器翻译。发布、编辑、登录、评论与跨设备播放同步未迁移。

当前开发者精选快照位于 `assets/guides/guides.json`：由原有本地 230 篇与 28 篇指定公开流程按 ID 去重合并，共 258 篇、覆盖 23 个文明。流程正文、结构数据、旗帜与游戏图标均随单文件 EXE 打包，阅读无需联网；应用内不提供更新或链接导入，只有开发者更换快照并重新构建才会变化。卡片上的“热门／经典／最新”仅对**已收录的离线内容**排序，不代表网站对应榜单的完整结果；已人工选择的补充条目与理由记录在 `assets/guides/curated_ids.json`。不保证每种打法在每个文明都有合适的公开流程，也不会用不相干的流程凑数。

开发者更新时可用 `python scripts/refresh_guide_bundle.py` 按清单读取指定流程并合并原有本地缓存，或在获得可分发的 JSON 后运行 `python scripts/prepare_guide_bundle.py <导出文件.json>`。两者都按流程 ID 去重，运行时程序本身不会访问 API。公开 API 不提供全站分页，站点也要求批量数据需求先联系作者；这些脚本不扫描 sitemap 或枚举全站 ID。第三方流程文字、图片的使用与再分发限制见 `assets/guides/NOTICE.txt`；若要公开分发 EXE，请先确认相关授权。

## 文明胜率

独立的原生 Qt 页面，默认显示[AOE4 World 排位单挑文明对阵](https://aoe4world.com/stats/rm_solo/matchups)的热力矩阵：行是我方文明，列是对手文明；每格显示我方胜率和场次数，“总体”列不含镜像对局。热力图行列与文明总览均按总体胜率（不含镜像）降序排列。行列标题仅显示国旗，悬停可查看文明全名。热力图默认随窗口缩放并完整显示，无需滚动；窗口很小时格子只显示胜率，悬停仍能查看场次数。按住 Ctrl 滚动鼠标滚轮可放大，放大后可使用滚动条；缩回原比例即恢复完整视图。另有文明总览（胜率、选择率、场次）和单文明对阵列表，可按官网当前补丁范围／单个补丁／全部补丁以及段位或分数筛选；段位与分数互斥。选中文明可跳至工具箱内对应的开局流程，选中对阵可在原站查看详情。

统计使用 AOE4 World [公开聚合 API](https://aoe4world.com/api/#stats)：每组筛选仅请求一次文明总览与一次对阵矩阵，不逐格抓取。首次打开及缓存超过 24 小时会尝试刷新；也可手动刷新。数据按筛选条件保存在当前用户的本地应用数据目录，断网时仍可看上次缓存并标记为历史数据。低于 100 场的格子弱化显示，此阈值是本工具的提醒而非官方判定。胜率与补丁、段位和样本量强相关，不能单凭颜色认定文明强弱。程序不调用个人战绩、回放或网页未文档化的对阵细分接口；接口使用边界见 `docs/aoe4world-stats-api-research.md`。

## 使用前须知

- 游戏窗口需处于前台，并在游戏里确认 `H`、`Q`、编队 0 的映射与你的设置一致。此工具只发送键盘事件，不读取游戏状态，也不会判断当前是否有足够资源训练村民。
- 每轮执行期间会短暂屏蔽物理键盘和鼠标输入，防止真实输入插入按键序列。优先使用 Windows `BlockInput`，失败时使用低级键鼠钩子。若目标游戏以管理员权限运行，可能也需要以相同权限运行本工具。
- `Ctrl+Alt+Delete` 等系统保留组合键无法模拟。运行前请保存其他工作；遇到键鼠无法响应时，可通过系统安全界面中断。
- BAT 方式首次运行需联网安装依赖；单文件 EXE 不需要 Python。若 EXE 在目标电脑无法启动，请查看 `%LOCALAPPDATA%\AOEvillager\AOE4Toolbox\aoe4toolbox.log`（为保留原有设置而沿用的内部路径，实际以系统 Qt 配置为准）。

源代码来自原连点器的循环输入与键鼠屏蔽模块；新项目没有鼠标连点功能，也不会修改原连点器文件。

## 版本管理与构建产物

Git 管理源码、练习数据、图标资源和启动/构建脚本。当前发布文件是 `dist\AOE4ReadyRoom.exe`；EXE、构建缓存、虚拟环境和自动生成的 `.spec` 文件不纳入 Git。需要重新构建时运行 `build_exe.bat`。
